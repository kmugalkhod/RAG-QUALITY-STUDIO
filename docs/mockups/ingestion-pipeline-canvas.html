Open question: where does "Inspect content" live?

The run list's Inspect content view (Extracted / Cleaned / Diff / Chunks, page overlays, cleaning audit, sensitive-data findings) is only in the editor today. The Knowledge Base snapshot page lists captured items, but I didn't see this inspector there. Before the run list is removed, pick one:

  • A (recommended): move the inspector to the Knowledge Base run/snapshot item view and link to it from the strip.
  • B: keep it in the editor as a "Run items" view in the same bottom drawer that preview uses.

Kept as-is

  • Node cards and their stage-state badges
  • Settings panel content per node
  • Error banner (inline, under the toolbar)
  • All actions. Each one moves somewhere else; none is dropped

Same as the answer editor (4bfcd17)

  • One toolbar row: identity on the left, actions on the right, one primary action at the far right
  • Save is primary while there are changes; Collect & publish is primary when the version is clean and saved
  • Discard shows only when there are unsaved changes
  • Validation strip only when Save is blocked
