Preview only the objects in a scoped bucket/prefix and publish a versioned index from the included files. The adapter has deterministic integration coverage; real AWS permissions and network behavior require a separately authorized account check.

## Prerequisites

Enable the local encrypted [source vault](../connections.md), save an **Amazon S3** connection, and grant its account read access only to a test bucket/prefix. Have embeddings configured for publication. The source node stores the connection ID, not the access key. Credentials and real object contents must not enter examples or screenshots. S3/API usage and embeddings may incur separate charges; dollar cost is unknown without account and model pricing.

## Configure and inspect

1. In **Pipelines → Ingestion pipelines → New ingestion pipeline**, select the Source node and choose **Amazon S3** under **Source type**. Choose **S3 connection**.
2. Set **AWS region**, **Bucket**, optional **Prefix**, and, when known, **Expected AWS account ID**. Under **Allowed file types**, select only the formats to ingest: TXT, PDF, MD, HTML, DOCX, PPTX, CSV, TSV or XLSX. The server accepts one to nine unique types.
3. Bound **Maximum objects**, **Maximum list pages**, bytes per object, total bytes and request timeout. Select **Preview processing**. Inspect item location, status and provider revision before saving. Save with **Save version**, then select **Run ingestion** and follow **Inspect published index** on success.

Expected result: only included objects under the saved prefix become members of the new ready index. The adapter records stable object identity and available version/ETag metadata; a refresh compares revisions, but an ETag alone is not a universal content hash. A failed required object blocks atomic publication. The controlled test checks changed, unchanged and removed objects; it does not establish access to your bucket.

If **No S3 connection is available**, return to **Settings**. If a test or preview reports access denied, verify region, bucket owner, prefix and permission before retrying. Inspect the run's per-object failure rather than broadening account access blindly. See [connections](../connections.md), [preview outcomes](../previews.md), and [source history](../source-history.md). This page applies to the schema-v2 source at the verified commit; live account validation remains a gate.
