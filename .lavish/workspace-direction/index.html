RAG Quality Studio needs to feel like a working tool.

The last pass improved navigation but missed the visual brief. Oversized serif headings, tinted page surfaces, loose rows and a large generic action panel made a small amount of information occupy the entire screen.

This board uses actual screenshots published by other products. They are references, not screenshots or promised capabilities of RAG Quality Studio. No application code is being changed in this design pass.

Dify: the primary reference for the editor

Let the canvas occupy the workspace. Keep execution actions in a compact top toolbar and configuration in a clearly bounded inspector.

Carry into our design

Small nodes with distinct type icons. A consistent row for model/index information. Compact Save and Test actions aligned at the upper right. Canvas tools grouped together.

Keep our actual scope

Our five supported nodes and explicit immutable saves remain. Branching, autosave, publishing and agent features in this reference are outside our implementation.

Linear: hierarchy and navigation

Carry into our design

Navigation that recedes behind the work. Consistent icon/text alignment. Separate project location from the page's action toolbar. Smaller page titles with stronger hierarchy between content and metadata.

Our visual choice

Use this restraint in a light interface: neutral gray sidebar, white content, dark text and one blue action color. Dark mode is not required to achieve this hierarchy.

Langfuse: a bounded Playground

Carry into our design

Configuration stays near the top, questions and outputs own the main area, and actions have predictable positions. Content lives inside a deliberate workspace instead of an endlessly growing form.

Adapt to RAG

One question/answer column and one evidence inspector. Saved pipeline/version selection above them; previous runs in a collapsible drawer. Multi-model comparison shown in the reference is not part of this task.

The proposed visual system

A precise light developer workspace. The following values are a proposal for review, not an implemented theme.

Content · #FFFFFF
Navigation · #F5F6F8
Text · #20232A
Action · #2563EB

Sans-serif throughout. Page titles 22–24px, body 14px, metadata 12px. A 216px project sidebar, 48px location bar, compact page toolbar, 44–48px document rows and a 320px detail inspector. Green signals Ready; amber signals active jobs; red signals failures. Color conveys state instead of covering the entire interface.

Next deliverable: one Knowledge Base design

Start with the populated Knowledge Base at desktop and mobile sizes. It will demonstrate navigation, typography, rows, status colors, upload and the document inspector using existing project data. Review that single composition before applying its system across all pages.
