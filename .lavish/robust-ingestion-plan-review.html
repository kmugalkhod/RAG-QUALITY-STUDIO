Processing model

One structured path after every connector

Delivery plan

Nine bounded phases

Phase Outcome Major functionality Must be true before moving on
0 · Correctness Truthful shared current path Freeze v1, schema v2 envelope, shared cleaners, Existing Files clean execution, upgrade-as-draft v1 unchanged; connector parity; real node execution
1 · Canonical IR Structured immutable derivations Pages, blocks, tables, spans, hashes, block-to-chunk lineage and bounded inspectors Every v2 chunk traces to exact source blocks
2 · Layout + OCR Complex and scanned PDFs Native/layout/auto profiles, page OCR fallback, languages, rotation, deskew, tables and quality measurements Mixed PDF succeeds; low quality cannot silently publish
3 · Cleaning Audited deterministic transforms Unicode, reflow, dehyphenation, headers/footers, web chrome, selectors and protected structures Every change attributable to one saved rule
4 · Chunking Structure-aware passages Section-token, parent/child, table rows, tokenizer bounds and separate embedding/evidence text Exact spans; citation-safe evidence; reusable snapshot variants
5 · Quality UX Inspect before embedding Policies, async preview, Raw/Extracted/Cleaned/Chunks inspector, metrics, warnings and cost Preview never changes durable retrieval state
6 · Dedupe + language Less redundant, correctly routed content Exact/near duplicates, canonical source, language detection/allowlist and OCR packs Every exclusion is explainable and reproducible
7 · Extensions Approved sensitive-data and formats Redaction policy; Markdown/HTML, DOCX, PPTX, CSV/TSV, XLSX, optional Tika boundary Each feature passes full end-to-end/security gates
8 · Evaluation Measured release and operations Golden corpus, OCR/layout/table/clean/chunk metrics, retrieval comparison, backup/restore and rollback Published thresholds pass on a clean isolated stack

Engineering guardrails

What keeps the implementation maintainable

Compatibility

Never rewrite history

V1 stays executable. New extraction, cleaning or chunking settings always create new immutable derivations and index versions.

Boundaries

Own contracts, adapt engines

Docling, OCRmyPDF or Tika never become the persisted domain model. Registry adapters normalize into application types.

Correctness

Evidence stays faithful

Heading enrichment belongs only in embedding text. Citation text and exact source spans remain separately stored.

Safety

Untrusted parsing is isolated and bounded

Workers enforce pages, pixels, memory, disk, time, blocks and output limits; logs and errors never contain raw source text.

Verification

Quality is measured, not asserted

Reviewed fixtures measure text, reading order, OCR, tables, boilerplate, source spans and downstream retrieval with failures included.

Recommended start

Implement Phase 0 only

  • It fixes current semantic gaps before adding dependencies.
  • It creates the shared boundary every later phase needs.
  • It proves backward compatibility and connector parity.
  • It intentionally excludes OCR, Docling, new derivation tables, semantic chunking, near-duplicate detection and PII.
